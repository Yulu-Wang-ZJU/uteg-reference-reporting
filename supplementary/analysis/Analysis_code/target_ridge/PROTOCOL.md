# Target-only Ridge comparator

Two focal SAHZU configurations, 15-minute four-coefficient input, same original 60-record target pool, 201 test records and seeds 1000–1019. This comparator uses no source labels, no source calibration and no residual correction. All four reference outputs are predicted. Input/output standardization is fitted on each training subset. Ridge has an unpenalized intercept; coefficients minimize sum of squared standardized residuals plus alpha times coefficient squared norm. Output projection matches the current workflow.

Select alpha from [0.1, 1, 10, 100] using mean held-out MA absolute error over the three recorded outer target folds; ties select the larger alpha. Confirm disjoint proxy groups and exact pool coverage in these folds. Fit the selected model on all 60 pool records. This development use is for selection only, not an unbiased estimate of performance. Freeze all 40 final models and hashes before a separate evaluation command reads test labels. Maximum 520 four-output regression solves (12 development plus one final per run); no retry search or additional hyperparameter values based on test results.

Evaluate ungated four-output MAE and complete MA class matrix, compare against saved complete-adaptation predictions and target-pool medians. All comparisons use identical records/seeds; paired 95% percentile intervals use 5,000 identity-proxy-group resamples retaining seeds. No report-gate comparison is claimed, so no artificial reuse of the existing gate on the new predictions. Any subsequent fair gate comparison requires its own matched development interface and separate authorization/protocol under the Goal scope.

This is exploratory analysis of a previously examined cohort, not independent confirmation. Preserve every run and result. Existing raw data/results and manuscript remain unchanged during fitting. Private final fitted objects stay local; aggregate outputs are candidates for supplementary data.
