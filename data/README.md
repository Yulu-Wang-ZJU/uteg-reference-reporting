# Supplementary Data

These eight workbooks are exact copies of the 18 November 2026 submission files. Read the README and Definitions sheets for metric denominators. Current sheets report 100-repeat summaries and retained aggregate repeat records. H_ sheets are the original fixed-cohort or exploratory analyses, with their original denominators.

1. Cohorts and nine configurations.
2. Mapping, adaptation, linear/RBF controls and Figure 2 (fixed 244-record illustration separately identified).
3. Reporting rules, class destinations, Figure 3 and exploratory associations.
4. Time checkpoints, locked first reports, updated final reports and HGB capability comparisons.
5. Sensitivity analyses, representations, component ablations and computation timing.
6. Target-only controls.
7. Local-data budgets and retained internal partitions.
8. Separate internal evaluation and ensemble extensions.

Main development size is 60; sensitivity uses 90% development sampling. The repeated internal analysis samples 271 of 301 records. Accuracy uses released reports; reporting rate uses all sampled test records. FNR/FPR use reported abnormal/normal references. Undefined ratios remain missing, with valid-repeat counts retained. Mean ± SD is not a confidence interval.

Tables contain aggregate counts and metrics, not individual patient records, identifiers, signals or prediction vectors. `current/repeat100/aggregate_results.zip` retains complete aggregate results for all repeats. Checksums are in `provenance/PUBLIC_DATA.json`.
